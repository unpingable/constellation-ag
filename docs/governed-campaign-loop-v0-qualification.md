## Frozen contract and state law

The packet contains exactly three stages and freezes one workspace, one
worker/model class, exact predecessor/result Git objects, one attempt and work
identity per stage, exact mutation paths and gates, all three complete NQ
profiles, and only the enumerated successor.

The durable phases are PREPARED, ADMITTED, EXECUTING, QUALIFYING, FROZEN, and
terminal HUMAN_REQUIRED or STOPPED. Restored EXECUTING can only reconcile its
exact attempt. Restored QUALIFYING can only replay evidence. Restored FROZEN
can only observe the packet-enumerated successor.

The controller API has no NQ status field and no caller-verdict constructor.
Its only positive input is an AG disposition bound to the exact current
Nightshift basis type, identity, resolver, source profile, successor, and work.

## Authority analysis

The controller acquired no standing, authorization, qualification,
successor-choice, continuation, settlement, or effect authority. Worker output
cannot select a successor. No stage advances without an exact current
Nightshift observation through NQ and AG authorization for enumerated work.
Restart cannot repeat a governed effect; Docket reconciliation is the only
lawful post-dispatch action. Qualification failure cannot advance. Resource
refusal cannot be reused. Control returns to a human after Stage 3.

Human decisions remaining are packet/profile approval, deployment binary and
resource-margin selection, handling indeterminate/stopped results, and all
work after Stage 3.

## Explicit V0 limitation

The qualified composition is a library driver plus a real cross-office
synthetic harness. It does not include a deployable Crow command binding the
office port to the production Docket subprocess and a systemd/cgroup unit.
The real specimen proves Git mutation, factual gates, NQ, Nightshift, and AG.
Docket dispatch/reconciliation and resource containment are qualified at the
port/state-law level and by unchanged existing corpora, not by one combined
Crow deployment run.

This limitation is material. V0 must not be represented as production-ready
until that adapter is implemented and qualified. That is a possible V1
pressure only; this campaign does not implement V1.
